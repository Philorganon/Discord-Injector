## Installation

### Prerequisites

- [Node.js](https://nodejs.org/) v18.0.0 or higher
- Discord Desktop App

### Quick Start

```bash
# Clone the repository
git clone https://github.com/Philorganon/Discord-Injector.git
cd Discord-Injector

# Install dependencies
npm install

# Inject with a theme
npm start install
```

---

## Usage

### Commands

```bash
# Install/inject with theme selection
npm start install

# Open live CSS editor
npm start editor

# Check injection status
npm start status

# List available themes
npm start themes

# Manage plugins
npm start plugins

# View/edit configuration
npm start config

# Run diagnostic tests
npm start test

# Restore original Discord
npm start restore
```

### Command Options

```bash
# Install with specific theme
npm start install -- -t dark-purple

# Open editor on custom port
npm start editor -- -p 9000

# Force restore without confirmation
npm start restore -- -f

# Enable a plugin
npm start plugins -- --enable theme-scheduler
```

## Themes

### Built-in Themes

| Theme | Description | Style |
|-------|-------------|-------|
| `dark-purple` | Dark theme with purple accents | Professional |
| `cyan-glow` | Cyberpunk-style cyan theme | Modern |
| `nord` | Nord color palette | Arctic |
| `dracula` | Classic Dracula theme | Iconic |
| `frosted-glass` | Glassmorphism effects | Elegant |
| `midnight-blue` | Deep blue dark theme | Minimal |
| `rose-gold` | Elegant rose gold accents | Sophisticated |

### Creating Custom Themes

Create a new `.css` file in `src/css/themes/`:

```css
/**
 * @name My Custom Theme
 * @author Your Name
 * @version 1.0.0
 * @description A beautiful custom theme
 * @tags dark, purple, modern
 */

:root {
    --background-primary: #1a1a2e;
    --background-secondary: #16213e;
    --text-normal: #eaeaea;
    --brand-experiment: #7c3aed;
}

/* Your custom CSS here */
```
